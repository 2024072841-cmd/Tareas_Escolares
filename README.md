# Proyecto: Tareas Escolares

Este es un proyecto académico desarrollado para practicar la creación de **APIs RESTful** utilizando tecnologías de backend.

## Descripción
Este proyecto permite la gestión de tareas escolares, sirviendo como base para comprender la arquitectura cliente-servidor y el manejo de rutas en entornos de desarrollo modernos.



## Backend
Para replicar este proyecto en un equipo diferente, asegúrate de tener instalado **Node.js**. A continuación, se detallan las herramientas y librerías clave utilizadas:

| Herramienta / Librería | Versión | Descripción |
| :--- | :--- | :--- |
| Node.js | v20.11.0 | Entorno de ejecución de JavaScript |
| Express | ^4.19.2 | Framework para la creación de la API |
| Dotenv | ^16.4.5 | Gestión de variables de entorno |
